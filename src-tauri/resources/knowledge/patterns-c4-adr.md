# Architecture logicielle — C4 + ADR

Quand on schématise :
- **C4 Context** : acteurs et systèmes externes.
- **C4 Containers** : apps/services déployables et leurs frontières.
- **C4 Components** : modules internes d'un conteneur.
- **ADR** : décision courte (contexte, décision, conséquences).

Sur un diagramme Fun : privilégier rectangles nommés, flèches directionnelles, notes de contrainte. Éviter le bruit décoratif.
