03 — Six Thinking Hats

Six angles, une tête claire

Faits, ressenti, opportunités, risques, décisions vertes, plan bleu.

W

Blanc — faits

  • Cible initiale web + mobile ; profil back (Spring/Node) + front Next/Angular
  • Cloud GCP · ~11 semaines total · MVP visé ~3 jours · solo, puis amis
R

Rouge — ressenti

  • État d’esprit chill ; envie de tester (mention Tori)
Y

Jaune — soleil

  • Intégrations pour cadrer un projet (prix, temps, plan)
  • Travail collectif entre amis, chacun sur son PC, pauses/jeux puis retour
  • Sentir qu’on avance ensemble même à distance
B

Noir — garde-fous

  • Features MVP qui cassent · mauvaise structure · trop de scope d’un coup
  • 3 jours = web seulement · K8s/Docker comme piège · benchmark IA difficile
  • Il faut un modèle qui marche vite pour ne pas bloquer le build
G

Vert — décisions

  • Ordre MVP : 1 canvas · 2 IA · 3 Pomodoro · puis le reste (jeux plus tard)
  • Repousser déploiement et jeux
Bl

Bleu — conduite

  • J1–2 : canvas · J2 aussi éducation/IA · ensuite Pomodoro
  • Jeux + intégrations : plus tard

07 — Five Whys

Descendre jusqu’à la racine

Pourquoi Fun ? Parce que le temps manque — et les outils aussi.

Pourquoi ?

Trop d’outils dispersés, fatigué d’utiliser les produits des autres — envie de réaliser Fun soi-même.

Pourquoi ?

Outils trop lents / fragmentés — vouloir démarrer vite, savoir quoi faire, voir le résultat rapidement.

Pourquoi ?

Peu de temps au quotidien — fenêtres = vacances (~5 jours) : MVP en 3 jours + 2 jours de repos.

Pourquoi ?

Pas le temps au quotidien.

Racine

Il y a un travail — d’où peu de temps hors vacances.

08 — Assumption Reversal

Retourner les présupposés

Survole une carte : l’hypothèse tombe, la décision se révèle.

hypothèse

« Il faut absolument le mobile dès le MVP. »

renversé

Abandon mobile MVP — cible PC / web desktop d’abord. Vision outil tout-en-un sur PC.

hypothèse

« draw.io doit être là dès le jour 1. »

renversé

MVP commence Excalidraw d’abord — draw.io reste dans le plan, pas abandonné.
